# PLAYER MARKET — Vercel 배포용

Next.js + JavaScript 기반 스포츠 선수 모의 거래 앱웹입니다. 최신 블랙·블러 UI, 별도 선수 목록, 거래 화면, 스포츠 카드 보관함을 포함합니다.

## Vercel에서 바로 배포

1. Vercel에서 **Add New → Project**를 선택합니다.
2. **sjh060623/mlbmarket** 저장소를 Import합니다.
3. Framework Preset은 **Next.js**, Root Directory는 **./**로 둡니다.
4. 환경 변수 없이 **Deploy**를 누릅니다.

소스가 저장소 최상위에 배치되어 있습니다. `vercel.json`에 `npm ci`와 `npm run build`를 설정했고, `package.json`은 Node.js `22.x`를 지정합니다. Output Directory는 기본값을 유지합니다. 실제 Vercel 계정에서의 배포 완료를 의미하지는 않습니다.

## GitHub 없이 Vercel CLI로 배포

Node.js 22가 설치된 컴퓨터에서 압축을 푼 폴더로 이동한 뒤 실행합니다.

```bash
npm install
npx vercel --prod
```

처음 실행하면 Vercel 로그인과 프로젝트 설정 안내가 나옵니다. 현재 폴더를 배포하고, Next.js 자동 감지 설정을 사용합니다. 인증 정보는 ZIP에 포함되어 있지 않습니다.

## 로컬 실행

```bash
npm ci
npm run dev
```

http://localhost:3000 에서 확인합니다.

```bash
npm test
npm run build
npm start
```

이 배포본은 일반 Next.js 빌드를 사용하므로 `.next/`가 생성됩니다. 정적 `out/` 출력 설정은 제거했습니다.

## 화면

- `/`, `/players/`: 선수 목록, 현재가·등락률·거래량, 검색·정렬·관심 필터
- `/trade/?player=ohtani&side=buy`: 선택 선수의 차트, 스탯, 주문
- `/cards/`: 스포츠 카드 보관함
- `/history/`: 거래 내역

모바일 앱 형태의 하단 탭과 최대 560px 화면 폭을 사용합니다. 웹 앱 매니페스트와 홈 화면 아이콘을 포함합니다. 오프라인 기능과 푸시 알림은 없습니다.

## 구현 범위

- 선수 12명 샘플 마켓, 타자·투수 필터와 관심 선수
- 캔들·선 차트, 기간 선택, 샘플 OHLC와 거래량
- 가상 자금 100만 P, 매수·매도, 수량 선택, 0.1% 수수료
- 잔액 부족·초과 매도·비정상 수량 차단
- 원가·평가손익·실현손익, 거래 메모와 체결 기록
- 매수 시 스포츠 카드 자동 발급, 선수 특징과 스탯, 카드 앞·뒷면
- 카드 ID·최초 매수일·스탯 스냅샷 보관, SVG 다운로드
- 추가 매수·부분 매도 시 카드 수량 갱신, 전량 매도 시 보유 카드 제외
- localStorage 저장·복원과 기존 데이터 호환

## 데이터와 저장

**실제 MLB API는 아직 연결되어 있지 않습니다.** 선수 소속·스탯·능력치·가격·거래량은 샘플이며, 시세 갱신은 시뮬레이션입니다. 실제 현금 결제, 환전, 암호화폐 발행, 사용자 간 주문 매칭은 없습니다.

계정·잔액·거래·카드는 현재 브라우저의 `player-market-v1` localStorage에 저장됩니다. 서버 데이터베이스·로그인·기기 간 동기화는 없습니다. 사이트 주소가 바뀌면 다른 저장 공간을 사용하므로 이전 데모 사이트의 보유 내역은 자동 이전되지 않습니다.

공식 선수 사진 대신 코드로 만든 타자·투수 일러스트를 사용합니다. 이전 스카우팅 노트는 저장 데이터에 보존하지만 메뉴에서는 제외했습니다.

```text

```

## 검증

거래·카드 발급·부분 및 전량 매도·스탯 보존·기존 데이터 이관·SVG 내보내기를 확인하는 테스트 8개와 프로덕션 빌드를 실행했습니다. 실제 Vercel 계정으로 배포한 결과 및 브라우저 직접 조작은 검증하지 않았습니다.
